# DrawGuessAI 🎨🤖

Welcome to **DrawGuessAI** — a fully self-contained, real-time artificial intelligence drawing recognition engine and multiplayer game. 

I built this project to explore the intersection of **Deep Learning for sequential time-series data**, **Real-Time WebSockets**, and **Distributed Multiplayer Game State Management**. This isn't just an image classifier; it uses an advanced sequence-based Recurrent Neural Network (LSTM) with a custom Attention Mechanism to interpret human drawing patterns stroke-by-stroke, live as you draw!

---

## 🚀 The Core Vision: Why I Built This

Traditional image classifiers (like CNNs) look at a finished drawing as a static 2D grid of pixels. But human drawing is inherently sequential—the order of strokes, the speed, and the pauses all carry massive amounts of semantic information. 

My goal was to build an engine that "**watches you draw**" and guesses what you are drawing in real-time, exactly like the popular game "Skribbl.io", but where the opponent is an AI. I expanded this into a full LAN/Hotspot Multiplayer game where players compete against each other to see who can get the AI to recognize their drawing the fastest!

---

## 🧠 The Machine Learning Architecture

At the heart of DrawGuessAI is a deep learning model trained on the massive **Google "Quick, Draw!" Dataset**. 

### 1. Data Representation (5D Stroke Vectors)
Instead of processing images, I engineered the client-side to track cursor movements and encode them into raw sequential temporal data. Every single stroke is converted into a sequence of 5-dimensional vectors:
* `Δx`: Change in X coordinate since the last point.
* `Δy`: Change in Y coordinate since the last point.
* `p1`: Pen down (currently drawing a continuous line).
* `p2`: Pen up (lifting the pen to move to a new stroke).
* `p3`: End of sketch (the drawing is complete).

### 2. Stroke Preprocessing Pipeline
To ensure the AI receives clean data regardless of screen size or mouse sensitivity, I implemented a custom preprocessing pipeline in JavaScript:
- **Douglas-Peucker Downsampling:** Reduces the sheer volume of points generated by 144Hz monitors, keeping only the mathematically significant vertices of curves.
- **Gaussian Smoothing:** Removes human jitter from the mouse/touchpad.
- **Scale Normalization:** Dynamically resizes the final temporal sequence so the bounding box fits precisely within a 255x255 coordinate grid, ensuring scale invariance.

### 3. Deep Learning Model (LSTM + Attention)
The 5D sequence is fed into a **PyTorch-based Deep Neural Network**:
- **2-Layer LSTM (Long Short-Term Memory):** With a hidden size of 256, this layer processes the time-series data to understand the contextual order of strokes (e.g., drawing the bun of a burger before the patty).
- **Custom Attention Layer:** I implemented an attention mechanism that calculates a context vector across all time steps. This allows the model to "focus" on the most defining strokes (e.g., the whiskers of a cat) rather than getting confused by generic foundational strokes.
- **Fully Connected Head:** A Dense layer network (`256 → 128 → ReLU → Dropout(0.3) → Output Logits`) maps the attention output to the final classification probabilities.

*(I trained the Solo model on 200 distinct classes, and a hyper-optimized Multiplayer version on 100 classes for ultra-low latency).*

## 🎮 The Multiplayer Game Engine

I built a completely custom, room-based multiplayer engine using **Python, Flask, and Socket.IO**.

### Real-Time Game State Machine
The server manages an authoritative state machine for multiple concurrent rooms. It handles:
- Room generation (4-letter codes) and lobby management.
- Synchronization of timers (5 rounds, 20 seconds each) across all connected clients to the millisecond.
- Handling edge cases like players disconnecting mid-round or the host ending the game early.

### Advanced Algorithmic Scoring
Scoring isn't just a boolean "Did you draw it or not?". I designed a dual-metric scoring formula:
1. **Confidence Bonus (Max 500 pts):** Based on the Softmax probability output of the LSTM. If the model is 99% sure your drawing is a "Dog", you get more points than if it's only 51% sure.
2. **Speed Bonus (Max 500 pts):** Using a linear decay algorithm based on the 20-second timer. Getting recognized at second 2 yields massively more points than at second 19.

### LAN / Hotspot Play
The multiplayer server dynamically binds to your machine's `0.0.0.0` network interface and prints your local IP. This allows anyone on the same Wi-Fi network (or mobile hotspot) to instantly join the game from their phone or laptop browser—zero installation required.

## 💻 How to Run It

### Requirements
- Python 3.10+
- Node.js 18+

### Mode 1: Solo Real-Time Prediction
This mode runs the distributed microservice architecture.

1. **Start the ML Server:**
   ```bash
   cd ml-model
   pip install -r requirements.txt
   python app.py
   ```
2. **Start the Node.js WebSocket Backend:**
   ```bash
   cd backend
   npm install
   node server.js
   ```
3. **Open the App:** Just double-click `frontend/index.html` in your browser and start drawing!

### Mode 2: Multiplayer LAN Game
This mode runs the fully integrated monolithic Flask-SocketIO engine.

1. **Install and Run:**
   ```bash
   cd multiplayer
   pip install -r requirements.txt
   python app.py
   ```
2. The terminal will output your Network IP address (e.g., `http://192.168.1.55:5000`). Give this URL to your friends on the same Wi-Fi to join your lobby!
